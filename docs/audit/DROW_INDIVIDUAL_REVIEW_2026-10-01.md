## Reproduced Gust cast-state defect — repair pending

`OnSpellStart` overwrites one `self.direction` and one `self.hit_targets` for the entire ability. `OnProjectileHit` later uses those shared values. Two overlapping casts (Refresher/debug cooldown reset) let the second direction control the first wave's push and let target deduplication leak/reset across waves. The existing regression covers only one cast.

Minimal reproduction: launch along +X, immediately launch along +Y, then deliver the first wave's hit to an enemy at(200,0). Expected push to(400,0); production pushes to(200,200). Appended offline test against current source fails at `first wave used the second cast direction` after211 existing tests pass. Scratch test/log: TEMP enfos-drow-overlap-repro.lua/.log. This proves mutable state logic, not actual engine overlap playback.
