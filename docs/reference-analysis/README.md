# Reference Analysis Directory

Each reference game gets its own analysis report.
Classification for each concept:
- `REFERENCE_ONLY` → study only, no implementation
- `ADAPT_CONCEPT` → mechanic idea fits us, reimplement from scratch
- `REJECT` → does not fit our game design

See: docs/REFERENCE_ANALYSIS_POLICY.md for rules.
