# References Directory

**These files are gitignored** — do not commit large game ZIPs/VPKs.

6. Guarding Athena / HADES → difficulty, progression, item development
7. Angel Arena Frontier / OAA → boss/item/hero upgrade systems
8. Epic Boss Fight Reborn → boss encounter design

## Usage
Download via SteamCMD or Workshop Tools, place files here.
