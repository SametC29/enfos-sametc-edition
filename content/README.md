# Content Source Directory

This directory is symlinked to `content/dota_addons/enfos_sametc` under the Dota 2 installation.
Workshop Tools uses this for source assets:
- Maps (.vmap)
- Particle sources (.vpcf)
- Material sources (.vmat)
- Model sources (.vmdl)

These are compiled by Workshop Tools into the `game/` directory.

**Requires**: Dota 2 Workshop Tools DLC to be installed.
