Git discipline:
- Treat one "operation" as one coherent logical work unit, not each line edit.

- Do not push known-broken work.
- Never force-push or routinely use destructive reset.

- Leave the working tree clean after completed work when possible.
- If a rebase/pull conflict is non-obvious, do not guess away another contributor's work.
